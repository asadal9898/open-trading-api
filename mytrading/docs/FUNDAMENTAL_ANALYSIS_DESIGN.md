# 펀더멘털 분석 + 차트 결합 설계

> 작성: 2026-06-30 / 갱신: 2026-07-12 (재무 3단계 평가 구현 완료)
> 핵심 원칙: **차트(기술적)만으론 부족하다. 재무(기본적)가 받쳐줘야 한다.**
> "상승장이라고 모든 종목이 오르는 게 아니다" — 업종·종목의 펀더멘털이 본질

---

## 0. 종목 평가 원칙 (차영석 확정)

**매수 조건: 재무 + 차트가 둘 다 좋아야 한다 (AND).**

- 재무만 좋고 차트가 나쁘면 → 매수 안 함 (아직 시장이 인정 안 함)
- 차트만 좋고 재무가 나쁘면 → 매수 안 함 (수급만의 상승, 위험)

**재무 평가 우선순위:**

| 순위 | 항목 | 상태 | 함수 |
|------|------|------|------|
| 1 | **부채** (작은 기업) | ✅ 구현 | `_debt_note` / `_match_debt_rule` |
| 2 | **영업이익** (지속·증가) | ✅ 구현 | `evaluate_operating_profit` |
| 3 | **배당** (인컴) | ✅ 구현 | `evaluate_dividend` |
| + | **PER** (저평가·이익추세) | ✅ 구현 | `get_per` / `get_quarterly_eps` |

**부채 동적 예외 (설계, 미구현):**
부채가 기준을 넘어도, **영업이익이 늘면서 부채가 줄어드는 추세**면 매수 가능.
"영업이익이 부채를 커버할 정도면 예외" — 정적 스냅샷이 아니라 개선 흐름을 봄.
→ PER(저평가)로도 접근 가능. 구현 시 결합.

## 1. 배경 — 왜 재무 분석인가

차트 분석만으로는 "왜 오르는지" 모른다. 실적이 받쳐주는 상승인지,
단순 수급 상승인지 구분이 안 된다. 한국 시장은 수급 급변이 잦아
차트만으론 위험하다. 펀더멘털(영업이익·매출·성장)이 차트를 보완해야 한다.

### 검증 사례 (2026-06-30)

| 종목 | 차트(우상향) | 영업이익증가율 | 매출증가율 | 해석 |
|------|------|------|------|------|
| 삼성전자 | 3/3 | **756.1%** | 69.2% | 차트+실적폭증 = 진짜 재평가 |
| HD현대중공업 | 3/3 | 108.7% | 54.8% | 조선 수주 → 실적 확인 |
| 코스맥스 | 0/3 | 3.3% | 15.9% | 차트 하락 + 재무 둔화 일치 |

## 2. 데이터 소스 — KIS + DART

| 소스 | 특성 | 제약 |
|------|------|------|
| **KIS** (finance_data.py) | 재무비율·EPS·성장률. 분기 30개 시계열 | **실전(prod) 전용** — 모의(vps)에선 불가 |
| **DART** (dart_data.py) | 전자공시 원천. 재무제표·EPS(기본주당이익) | 모드 무관. 조회 느림 |
| **통합** (finance_unified.py) | KIS 우선 + DART 폴백/교차검증 | |

**교차검증 실측 (삼성전자 2025, DART/KIS):**
Q1 1192/1186, Q2 737/734, Q3 1802/1781, 연간 6605/6564
→ **두 독립 소스가 1% 이내 일치.** 데이터 신뢰도 확인.

**중요 차이**: KIS 분기 EPS는 **누적(YTD)** → 차분 필요. DART는 **단일 분기** 값.

**레이트리밋 주의**: 종목마다 API를 여러 번 호출하므로, 여러 종목 스캔 시
호출 간 텀(2초 등)이 필요. 없으면 "초당 거래건수 초과" 에러.

## 3. 부채 (재무 1순위) — 업종별 기준

**부채비율을 모든 업종에 일률 적용하면 안 된다.**

### 3-1. 업종별 부채 성격

| 업종 | 부채 성격 | 해석 |
|------|------|------|
| 은행 | 예금=부채 | 부채비율 무의미 (예금 많은 게 영업력). 대체: BIS비율 |
| 보험 | 보험부채(시가) | 부채비율 무의미. 대체: K-ICS |
| 증권 | 예탁금·RP | 부채비율 무의미 (레버리지 업) |
| 조선(선박) | 선수금=부채 | 부채 많으면 오히려 긍정 (수주 많음) |
| 건설 | PF·선수금 | 업 특성상 높음 |
| 항공·유통 | 리스부채(IFRS16) | 회계상 급증, 실제 악화 아님 |
| 일반 제조 | 실제 차입 | 표준 적용 |

### 3-2. 구현 — `debt_industry_rules` (config)

키워드 매칭 + 섹터 + 기준값. KIS industry(표준산업분류 텍스트)에 키워드 포함 시 적용.

```yaml
debt_industry_rules:
  "은행":  { sector: "금융",   debt: none }   # none = 부채비율 판단 제외
  "보험":  { sector: "금융",   debt: none }
  "증권":  { sector: "금융",   debt: none }
  "여신":  { sector: "금융",   debt: none }
  "금융":  { sector: "금융",   debt: none }
  "선박":  { sector: "산업재", debt: 200 }    # 조선 — 선수금
  "건설":  { sector: "건설",   debt: 150 }
  "항공":  { sector: "산업재", debt: 200 }    # 리스부채
  "도매":  { sector: "유통",   debt: 130 }
debt_default: { sector: "기타", debt: 100 }   # 그 외 (일반 제조 등)
```

**검증**: 조선250%→보통(기준200) / 금융→판단제외 / 반도체250%→높음(기준100) / 건설140%→양호(기준150)

## 4. 영업이익 (재무 2순위) — 구현 완료

### 4-1. 기준 (config `op_profit_rules`)

**1) 흑자 지속성**: 최근 5년 중 3년 이상 흑자
- 위기연도(2008 리먼·2020 코로나) 제외 — 시스템 위기는 회사 잘못 아님

**2) 최근 분기 영업이익증가율 (YoY, 작년 동기 대비)**
- **YoY를 쓰는 이유**: 계절성 상쇄. 전분기 대비(QoQ)는 성수기·비수기 왜곡.
- KIS `bsop_prfi_inrt` (분기 조회) 첫 행 = 최근 분기.

| 증가율 | 등급 | 점수 |
|--------|------|------|
| +50% 이상 | 대호재 | 계단식 |
| +25% 이상 | 호재 | 계단식 |
| +10% 이상 | 좋음 | +1 |
| ±10% | 보통 | 0 |
| -10% 이하 | 경고 | -1 |
| -25% 이하 | 위험 | 계단식 |
| -50% 이하 | 대악재 | 계단식 |

**점수 규칙**: |증가율| >= 25%면 **부호 × (1 + |증가율| ÷ 25)**, 미만이면 고정 점수.
- +25%→+2, +50%→+3, +100%→+5, **+756%→+31**
- -25%→-2, -50%→-3, -100%→-5
- **상한 없음** (차영석 확정). ⚠️ 결합 설계 시 정규화 검토 필요 —
  영업이익만 +31이면 다른 지표(부채·PER·차트)가 묻힘.
- 경계: 양수는 "이상", 음수는 "이하" (-10% = 경고)

**passed** = 흑자 지속성 AND 등급이 위험/대악재 아님.

**검증**: 삼성전자 +756%→대호재(+31) / 고려신용정보 +10.8%→좋음(+1) / 모토닉 -4.9%→보통(0)

### 4-2. 영업이익률(마진)은 보류 — 영업 레버리지 문제

**마진을 절대 기준으로 쓰면 위험하다** (차영석 통찰).

고정비 비중이 높은 구조는 마진이 경기에 극도로 민감:
- **호황**: 매출↑ but 고정비 그대로 → 늘어난 매출이 거의 다 이익 → **마진 급등**
- **불황**: 매출↓ but 고정비 그대로 → **마진 급락** (심하면 적자)

예: 현대차 **직영점**(임대료·인건비 고정) vs 대리점(수수료=변동비).
고정비 큰 업종 — 반도체(팹), 항공(기재), 조선(도크), 철강(고로), 직영 유통.

**"마진 10% 이상만 매수" 같은 절대 기준의 함정:**
반도체 호황기엔 다 통과(마진 30%), 불황기엔 다 탈락(마진 -10%)
→ **고점에서 사고 저점에서 안 사는** 최악의 결과.

**→ 마진은 4-3의 "사이클 산업 PER 함정"과 같은 뿌리.
업종별 PER 해석 규칙을 만들 때 함께 다룬다. (미구현, 잊지 말 것)**

## 5. 배당 (재무 3순위) — 국고채 연동

### 5-1. 기준 (config `dividend_filter`)

**시가배당률 >= 국고채 3년물 + 프리미엄**

- **코스피 +0.5%p / 코스닥 +1.0%p** (보수적 — 너무 높이면 통과 종목이 사라짐)
- **국고채 3년물이 한국 시장금리 벤치마크** (미국·일본은 10년물).
  한국 국채시장은 3년물 유동성이 가장 깊고, 배당주는 중기 보유 자산이라 3년물과 비교가 합리적.
- **금리가 오르면 배당 요구수익률도 자동 상승** — 고정값이면 못 잡는 변화.

```yaml
dividend_filter:
  base_rate_source: kcif        # kcif(자동) | fixed(rate_threshold 사용)
  fallback_rate: 3.5            # KCIF 못 읽을 때
  kospi:   { premium: 0.5, rate_threshold: 4.0, ... }
  kosdaq:  { premium: 1.0, rate_threshold: 4.5, ... }
```

### 5-2. 국고채 데이터 — KCIF INSIGHT 연동 ★

`get_base_rate()` 가 KCIF 파싱 YAML에서 자동으로 읽는다:

```
kcif_insight_key_indicators_history.yaml
  history / {최신호} / categories / 국내 채권시장 / 시장금리 / 국고채 3년
  → 시계열의 마지막 값 = 최근월 금리
```

**현재 3.72%** (2026-06호). 상승 추세: 3.04 → 3.56 → 3.59 → 3.72
→ 배당 기준: 코스피 4.22% / 코스닥 4.72%

**※ 거시(KCIF 금리) → 미시(종목 배당 판정) 연결의 첫 사례.**
DECISION_LAYER_DESIGN의 "거시가 미시를 지배" 원칙이 실제로 구현된 것.
KCIF 보고서가 갱신되면 배당 기준도 자동으로 따라 움직인다.

**검증**: 모토닉 8.20%>4.22% 통과 / 고려신용정보 5.32%>4.72% 통과 / 삼성전자 0.13% 미달

## 6. PER — 저평가·이익추세

### 6-1. 3가지 용도

1. **부채 예외** — 부채 높아도 저PER면 통과 검토
2. **저평가 판정** — 종목 평가 항목
3. **분기 이익추세** — EPS 흐름으로 실적 방향 확인

### 6-2. 구현

`finance_data.py`:

- `_quarter_standalone(rows)` — KIS 누적 EPS → 단일 분기 차분
- `get_quarterly_eps(symbol)` — 분기 EPS 추세 + TTM(최근 4분기 합)
- `get_per(symbol)` — 연간 PER + TTM PER, **모드 인지 + 교차검증**
  - 모의(vps): DART만 / 실전(prod): KIS + DART, 차이 3% 초과 시 경고

`dart_data.py`:

- `get_eps(code, year, period)` — DART 기본주당이익
  (계정명 변형 대응: "기본주당이익" / "기본주당이익(손실)")

### 6-3. PER 해석 주의 — 사이클 산업 ⚠️

**삼성전자 실측 (2026-07, 278,000원):**

- 연간 PER **42.4** (2025 실적 EPS 6564) — 비싸 보임
- TTM PER **22.5** (최근 4분기 EPS 12371) — 실적 개선 반영

**어느 EPS를 쓰냐에 따라 저평가 판정이 정반대.** 분기 추세를 봐야 하는 이유.

**메모리 쇼티지 (차영석 통찰):** 메모리는 수요가 **비탈력적**(가격 올라도 서버·AI
인프라는 사야 함) → 공급이 조금만 부족해도 가격 급등 (곡물·주택과 같은 메커니즘).
판가 상승이 곧 마진 → EPS 폭증 (2026 Q1 6993, 작년 연간 6564 초과).

**사이클 업종 PER 함정**: 반도체·화학·조선 등은 이익 정점에서 PER가 낮게 나옴.
**저PER가 오히려 고점 신호**일 수 있음. 안정 산업(통신·유틸리티)의 저PER와 의미가 다름.
→ **업종별 PER 해석 규칙 필요** (부채처럼). 4-2의 마진 문제와 함께. **미구현.**

## 7. 구현 현황

1. ✅ KIS 재무 API 확인, 영업이익·성장률 검증
2. ✅ industry(표준산업분류) 필드
3. ✅ 재무 지표 함수 — get_financials / get_growth / get_operating_profit / get_financial_summary
4. ✅ **부채 (1순위)** — debt_industry_rules (키워드+섹터+기준값), _debt_note
5. ✅ **PER** — get_per (연간·TTM), get_quarterly_eps, DART 교차검증
6. ✅ **영업이익 (2순위)** — evaluate_operating_profit (흑자 지속성 + 분기 YoY 등급·점수)
7. ✅ **배당 (3순위)** — evaluate_dividend (국고채 3년물 + 프리미엄, KCIF 연동)
8. ⬜ **부채 동적 예외** — 영업이익↑&부채↓ 추세면 상한 초과 허용 (설계만)
9. ⬜ **차트 "좋다"의 정의** — AND의 나머지 반쪽
   (trend_score·get_trend 존재하나 판정 기준 미정)
10. ⬜ **재무 + 차트 결합** — 하나의 종목 신호로 (0장 AND 원칙 구현)
    ※ 점수 스케일 정규화 필요 (영업이익 +31 vs 부채 +2 → 불균형)
11. ⬜ **백테스트 검증** — 결합 규칙이 실제 수익인지 ★최난
    (과거 시점 재무 데이터, 룩어헤드·생존편향)
12. ⬜ **업종별 PER 해석 + 마진 해석** — 사이클 산업 함정 (4-2, 6-3)
13. ⬜ **텔레그램 알림** — 영업이익 |증가율| >= 25%면 알림 (notify_threshold).
    종목 평가 크론 만들 때 연결.

## 9. 회계기준 변경 + 금융업 특수 (차영석 통찰, 설계 기록)

> ⚠️ 이 장은 **통찰·설계 기록**. 세부(보험주 매도압력, 회계기준 시점 관리)는

### 9-1. 회계기준 — 바젤 vs IFRS (다른 것)

**바젤(Basel I/II/III)** — 은행 자본규제

- BIS 회의에서 정함. 국가마다 시행 시기 단계적
- 한국은 바젤3 도입을 미뤄 경고받은 적 있음
- 역사: 바젤1(1988)이 일본 버블 붕괴 한 원인 (자본규제 맞추려 자산 매각 → 하락 가속)

**IFRS(국제회계기준)** — 재무제표 작성 기준

- IFRS 16 (리스): 미래 리스료를 부채로 → 유통·항공 부채비율 급증 (회계상)
- IFRS 17 (보험): 2023년 시행, 보험부채 시가평가
- IFRS 9 (금융자산): 보험사엔 IFRS 17과 동시 도입

### 9-2. 보험업 특수 — 주식 매도 압력 (미구현)

2023년 IFRS 17 + K-ICS 전면 전환:

- 보험부채 원가평가 → 시가평가 (금리 따라 변동)
- **K-ICS 주식충격: 8% → 35%** 하락 시나리오로 상향 → 요구자본 급증
- 보험사가 주식 보유 시 자본 부담 4배↑ → **주식 줄일 유인**
- 영향: 보험주 + 보험사 보유 많은 종목 = 매도 물량 압력

**보험주 금리 민감**: 보험 P/B와 국고채 10년물 상관 0.76 → 거시(금리) 레이어와 직결

**투자 방침**: 보험은 회계·규제 복잡 + 매도압력 → 신중 (차영석 "위험한 곳")

### 9-3. 회계기준 시점 주의

- IFRS 17: 2023년 전후 보험 재무제표 비교 불가 (기준 전면 변경)
- 과거-현재 재무 비교 시 "같은 기준 기간끼리"
