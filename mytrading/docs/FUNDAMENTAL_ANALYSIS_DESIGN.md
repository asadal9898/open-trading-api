# 펀더멘털 분석 + 차트 결합 설계

> 작성: 2026-06-30 / 갱신: 2026-07-11 (업종별 부채 규칙·PER 구현 반영)
> 핵심 원칙: **차트(기술적)만으론 부족하다. 재무(기본적)가 받쳐줘야 한다.**
> "상승장이라고 모든 종목이 오르는 게 아니다" — 업종·종목의 펀더멘털이 본질

---

## 0. 종목 평가 원칙 (차영석 확정, 2026-07-11)

**매수 조건: 재무 + 차트가 둘 다 좋아야 한다 (AND).**

- 재무만 좋고 차트가 나쁘면 → 매수 안 함 (아직 시장이 인정 안 함)
- 차트만 좋고 재무가 나쁘면 → 매수 안 함 (수급만의 상승, 위험)

**재무 평가 우선순위:**

1. **부채** — 작은 기업 (안정성 최우선)
2. **영업이익** — 지속·증가
3. **배당** — 인컴

**부채 동적 예외 (설계, 미구현):**
부채가 기준을 넘어도, **영업이익이 늘면서 부채가 줄어드는 추세**면 매수 가능.
"영업이익이 부채를 커버할 정도면 예외" — 정적 스냅샷이 아니라 개선 흐름을 봄.
→ PER(저평가)로도 접근 가능. 구현 시 결합.

## 1. 배경 — 왜 재무 분석인가

차트 분석만으로는 "왜 오르는지" 모른다. 실적이 받쳐주는 상승인지,
단순 수급 상승인지 구분이 안 된다. 한국 시장은 수급 급변이 잦아
차트만으론 위험하다. 펀더멘털(영업이익·매출·성장)이 차트를 보완해야 한다.

### 검증 사례 (2026-06-30)

| 종목 | 차트(우상향) | 영업이익증가율 | 매출증가율 | 해석 |
|------|------|------|------|------|
| 삼성전자 | 3/3 | **756.1%** | 69.2% | 차트+실적폭증 = 진짜 재평가 |
| HD현대중공업 | 3/3 | 108.7% | 54.8% | 조선 수주 → 실적 확인 |
| 코스맥스 | 0/3 | 3.3% | 15.9% | 차트 하락 + 재무 둔화 일치 |

## 2. 데이터 소스 — KIS + DART

| 소스 | 특성 | 제약 |
|------|------|------|
| **KIS** (finance_data.py) | 재무비율·EPS·성장률. 분기 30개 시계열 | **실전(prod) 전용** — 모의(vps)에선 불가 |
| **DART** (dart_data.py) | 전자공시 원천. 재무제표·EPS(기본주당이익) | 모드 무관. 조회 느림 |
| **통합** (finance_unified.py) | KIS 우선 + DART 폴백/교차검증 | |

**교차검증 실측 (삼성전자 2025, DART/KIS):**
Q1 1192/1186, Q2 737/734, Q3 1802/1781, 연간 6605/6564
→ **두 독립 소스가 1% 이내 일치.** 데이터 신뢰도 확인.

**중요 차이**: KIS 분기 EPS는 **누적(YTD)** → 차분 필요. DART는 **단일 분기** 값.

## 3. 업종별 재무 해석 (차영석 통찰) — 구현 완료

**부채비율을 모든 업종에 일률 적용하면 안 된다.**

### 3-1. 업종별 부채 성격

| 업종 | 부채 성격 | 해석 |
|------|------|------|
| 은행 | 예금=부채 | 부채비율 무의미 (예금 많은 게 영업력). 대체: BIS비율 |
| 보험 | 보험부채(시가) | 부채비율 무의미. 대체: K-ICS |
| 증권 | 예탁금·RP | 부채비율 무의미 (레버리지 업) |
| 조선(선박) | 선수금=부채 | 부채 많으면 오히려 긍정 (수주 많음) |
| 건설 | PF·선수금 | 업 특성상 높음 |
| 항공·유통 | 리스부채(IFRS16) | 회계상 급증, 실제 악화 아님 |
| 일반 제조 | 실제 차입 | 표준 적용 |

### 3-2. 구현 — `debt_industry_rules` (config)

키워드 매칭 + 섹터 + 기준값 구조. KIS industry(표준산업분류 텍스트)에
키워드가 포함되면 해당 규칙 적용.

```yaml
debt_industry_rules:
  "은행":  { sector: "금융",   debt: none }   # none = 부채비율 판단 제외
  "보험":  { sector: "금융",   debt: none }
  "증권":  { sector: "금융",   debt: none }
  "여신":  { sector: "금융",   debt: none }
  "금융":  { sector: "금융",   debt: none }
  "선박":  { sector: "산업재", debt: 200 }    # 조선 — 선수금
  "건설":  { sector: "건설",   debt: 150 }
  "항공":  { sector: "산업재", debt: 200 }    # 리스부채
  "도매":  { sector: "유통",   debt: 130 }
debt_default: { sector: "기타", debt: 100 }   # 그 외 (일반 제조 등)
```

※ 기준값은 **시작값** — 운영하며 조정 예정.

**코드** (`finance_data.py`):

- `_load_debt_rules()` — config 로드
- `_match_debt_rule(industry)` — 키워드 포함 매칭 → {sector, debt}
- `_debt_note(debt_ratio, industry)` — 업종 상한 대비 판정
  (none이면 "판단 제외", 숫자면 양호/보통/높음)

**검증**: 조선250%→보통(기준200) / 금융→판단제외 / 반도체250%→높음(기준100) / 건설140%→양호(기준150)

## 4. PER — 저평가·이익추세 (구현 완료)

### 4-1. 3가지 용도

1. **부채 예외** — 부채 높아도 저PER면 통과 검토
2. **저평가 판정** — 종목 평가 항목
3. **분기 이익추세** — EPS 흐름으로 실적 방향 확인

### 4-2. 구현

`finance_data.py`:

- `_quarter_standalone(rows)` — KIS 누적 EPS → 단일 분기 차분
- `get_quarterly_eps(symbol)` — 분기 EPS 추세 + TTM(최근 4분기 합)
- `get_per(symbol)` — 연간 PER + TTM PER, **모드 인지 + 교차검증**
  - 모의(vps): DART만 (KIS 재무 불가)
  - 실전(prod): KIS + DART 둘 다 → 차이 3% 초과 시 `cross_check` 경고

`dart_data.py`:

- `get_eps(code, year, period)` — DART 기본주당이익
  (계정명 변형 대응: "기본주당이익" / "기본주당이익(손실)")
- `get_quarterly_eps(code, year)` — 분기 4개 + Q4 계산

### 4-3. PER 해석 주의 — 사이클 산업

**삼성전자 실측 (2026-07, 278,000원):**

- 연간 PER **42.4** (2025 실적 EPS 6564 기준) — 비싸 보임
- TTM PER **22.5** (최근 4분기 EPS 12371) — 실적 개선 반영

**어느 EPS를 쓰냐에 따라 저평가 판정이 정반대.** 분기 추세를 봐야 하는 이유.

**메모리 쇼티지 (차영석 통찰):** 메모리는 수요가 **비탈력적**(가격 올라도 서버·AI
인프라는 사야 함) → 공급이 조금만 부족해도 가격 급등 (곡물·주택과 같은 메커니즘).
판가 상승이 곧 마진 → EPS 폭증 (2026 Q1 6993, 작년 연간 6564 초과).

**⚠️ 사이클 업종 PER 함정**: 반도체·화학·조선 등은 이익 정점에서 PER가 낮게 나옴.
**저PER가 오히려 고점 신호**일 수 있음. 안정 산업(통신·유틸리티)의 저PER와 의미가 다름.
→ 업종별 PER 해석 규칙 필요 (부채처럼). **미구현.**

## 5. 구현 현황

1. ✅ KIS 재무 API 확인, 영업이익·성장률 검증
2. ✅ industry(표준산업분류) 필드
3. ✅ **재무 지표 함수** — get_financials / get_growth / get_operating_profit /
   get_financial_summary
4. ✅ **업종별 부채 규칙** — debt_industry_rules (키워드+섹터+기준값), _debt_note
5. ✅ **PER** — get_per (연간·TTM), get_quarterly_eps, DART 교차검증
6. ⬜ **부채 동적 예외** — 영업이익↑&부채↓ 추세면 상한 초과 허용 (설계만)
7. ⬜ **영업이익 기준** — "좋다"의 정의 (연속 흑자? 증가율?) — 재무 2순위
8. ⬜ **배당 기준** — 재무 3순위 (배당주 필터엔 있으나 종목평가 통합 안 됨)
9. ⬜ **차트 "좋다"의 정의** — AND의 나머지 반쪽
   (trend_score·get_trend 존재하나 판정 기준 미정)
10. ⬜ **재무 + 차트 결합** — 하나의 종목 신호로 (0장 AND 원칙 구현)
11. ⬜ **백테스트 검증** — 결합 규칙이 실제 수익인지 ★최난
    (과거 시점 재무 데이터, 룩어헤드·생존편향)
12. ⬜ **업종별 PER 해석** — 사이클 산업 저PER 함정 (4-3)

## 7. 회계기준 변경 + 금융업 특수 (차영석 통찰, 설계 기록)

> ⚠️ 이 장은 **통찰·설계 기록**. 아래 세부(보험주 매도압력, 회계기준 시점 관리)는
> 아직 코드 미반영. 3장의 부채 규칙에는 "금융=판단 제외" 수준으로만 반영됨.

### 7-1. 회계기준 — 바젤 vs IFRS (다른 것)

**바젤(Basel I/II/III)** — 은행 자본규제

- BIS 회의에서 정함. 국가마다 시행 시기 단계적
- 한국은 바젤3 도입을 미뤄 경고받은 적 있음
- 역사: 바젤1(1988)이 일본 버블 붕괴 한 원인 (자본규제 맞추려 자산 매각 → 하락 가속)

**IFRS(국제회계기준)** — 재무제표 작성 기준

- IFRS 16 (리스): 미래 리스료를 부채로 → 유통·항공 부채비율 급증 (회계상)
- IFRS 17 (보험): 2023년 시행, 보험부채 시가평가
- IFRS 9 (금융자산): 보험사엔 IFRS 17과 동시 도입

### 7-2. 보험업 특수 — 주식 매도 압력 (미구현)

2023년 IFRS 17 + K-ICS 전면 전환:

- 보험부채 원가평가 → 시가평가 (금리 따라 변동)
- **K-ICS 주식충격: 8% → 35%** 하락 시나리오로 상향 → 요구자본 급증
- 보험사가 주식 보유 시 자본 부담 4배↑ → **주식 줄일 유인**
- 영향: 보험주 + 보험사 보유 많은 종목 = 매도 물량 압력

**보험주 금리 민감**: 보험 P/B와 국고채 10년물 상관 0.76 → 거시(금리) 레이어와 직결

**투자 방침**: 보험은 회계·규제 복잡 + 매도압력 → 신중 (차영석 "위험한 곳")

### 7-3. 회계기준 시점 주의

- IFRS 17: 2023년 전후 보험 재무제표 비교 불가 (기준 전면 변경)
- 과거-현재 재무 비교 시 "같은 기준 기간끼리"
