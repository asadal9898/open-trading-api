## 1. 구현 완료 — 종목 평가 (재무 AND 차트)

### 원칙

**매수 = 재무 좋음 AND 차트 좋음.** 같은 차트를 스타일별로 정반대 해석.

| style | 재무 기준 | 차트 기준 | 성격 |
|-------|----------|----------|------|
| `value_range` (배당주) | 부채 + 영업이익 + **배당(필수)** | **52주 저점 근처** | 소외되어 싸질 때 산다 |
| `momentum` (공격적) | 부채 + 영업이익(**+10%↑**) | **정배열 (5>20>60)** | 추세를 따라간다 |
| `accumulate` (ETF) | **스킵** | 20일선 위 | 섹터 전망 + 차트 ※섹터전망 미구현 |
| `free_holdings` | 알림만 | 알림만 | 사람이 판단 |

### 파일

- `finance_data.py` — 재무 (부채·영업이익·배당·PER, `evaluate_financials`)
- `chart_eval.py` — 차트 (정배열 / 52주 저점, `evaluate_chart`)
- `stock_eval.py` — 결합 (`evaluate_stock` = 재무 AND 차트)
- `mytrading_config.yaml` — `style_rules`, `chart_rules`, `debt_industry_rules`, `op_profit_rules`, `dividend_filter`

## 3. ★★★ value_range 최종 전략 (확정)

### 3-1. 전략

```
[매수]  52주 저점 +5% 이내  AND  국면 ≠ 침체
[매도]  매수가 대비 +15% 익절
[손절]  -30%
```

### 3-2. 국면 판정 (2단계) — 기저효과 회피

**단순 YoY만 보면 속는다.** 5년 동일분기 평균을 함께 본다.

```
1단계: |YoY| < 25%  → "평범"
2단계: |YoY| >= 25% → 5년 동일분기 평균과 비교
```

| YoY | 5년평균 대비 | 국면 | 매수 |
|-----|------------|------|------|
| 증가 | +20% 이상 | 성장 | O |
| 증가 | +20% 미만 | 턴어라운드 | O |
| 감소 | 위 | 정점통과 | O |
| **감소** | **아래** | **침체** | **X ← 매수 금지** |

**침체 = 영업이익 YoY -25% 이하 AND 5년 평균 미달.**

### 3-3. 성과 (33종목, 2년, 실제 배당 반영)

| 익절 | 주가수익 | 배당수익 | **총수익** | 중앙값 | 승률 |
|------|---------|---------|----------|--------|------|
| **+15%** | +6.8% | +6.4% | **+13.2%** | **+16.4%** | **76%** |
| +20% | +7.6% | +8.6% | +16.2% | +12.3% | 67% |

**+15% 권장** — 중앙값·승률이 안정적. (+20%는 평균이 높지만 유아이엘 +79% 같은
대박에 의존, 승률은 낮음)

**배당이 수익의 절반.** 손실을 방어한 사례:

| 종목 | 주가 | 배당 | 총 |
|------|------|------|-----|
| 정상제이엘에스 | -12.3% | **+16.2%** | **+3.8%** (흑자 전환) |
| 진양홀딩스 | -1.6% | +11.4% | +9.8% |
| 동국홀딩스 | +21.3% | **+29.3%** | +50.7% |

## 4. ★★ 검증 결론 — 단순한 게 이긴다

### 4-1. 전략별 성적 (value_range, 2년)

| 전략 | 평균 | 중앙값 | 비고 |
|------|------|--------|------|
| **저점매수 + 침체제외 + 익절15%** | **+13.2%** (배당포함) | +16.4% | ★채택 |
| 저점매수 + 침체제외 (손절만) | +10.9% | +11.0% | 배당 미포함 |
| VR 단순 (필터 없음) | +5.9% | +5.5% | |
| 4단계 분할 매수 | -0.5% | -1.1% | 복잡 |
| 모아가기 v2 (주 0.5%) | -0.3% | -0.3% | 복잡 |
| 모아가기 v3 (주 2%) | -0.6% | -1.0% | 복잡 |
| 모아가기 v4 (90% 매도) | -1.0% | -0.6% | 복잡 |

**정교하게 만들수록 나빠졌다.**

### 4-2. "뭘 살까" > "어떻게 팔까"

| 조정 | 효과 |
|------|------|
| **매수 필터(침체 제외) 추가** | +5.9% → **+10.9%** (**+5.0%p**) |
| 손절선 최적화 (-10~-40% 비교) | +10.6% → +10.9% (**+0.3%p**) |
| 매도 전략 정교화 (4종 비교) | 차이 거의 없음 |

**매수 필터가 5%p를 만들고, 매도·손절은 0.3%p뿐.**

### 4-3. 손절선 최적화 결과

| 손절 | 평균 | 승률 |
|------|------|------|
| 없음 | +10.6% | 79% |
| -10% | **+4.3%** | 52% ← 타이트하면 좋은 종목도 털어냄 |
| -15% | +6.7% | 61% |
| -20% | +9.7% | 73% |
| **-25%** | **+10.9%** | 79% |
| -30% | +9.8% | 76% |
| -40% | +10.6% | 79% (= 손절 없음) |

**타이트한 손절이 오히려 해롭다.** 배당주는 변동이 커서 -10% 정도는 자주 나온다.

### 4-4. 국면 필터 조합

| 매수 허용 국면 | 평균 | 승률 |
|---------------|------|------|
| 전부 허용 | +5.3% | 65% |
| **침체 제외 ★** | **+10.9%** | **79%** |
| 침체+정점통과 제외 | +10.8% | 79% |
| 성장만 | +9.5% | 78% (종목 18개로 감소) |
| 성장+턴어라운드만 | +8.7% | 83% (종목 23개) |

**"침체 제외" 하나면 충분.** 더 조이면 매수 기회가 줄어 수익도 준다.

## 5. 백테스트에서 발견한 함정

### 5-1. ★ 52주 고점 매도의 롤링 창 문제 (버그)

```
태경산업: 5,590 매수 → 5,450 매도 (-2.5%)  "고점매도"
```

**손실인데 "고점매도"?** 원인: **52주 고점이 내려왔다.**

```
매수 시점: 52주 고점 8,000원 → 5,590은 고점 대비 -30%
1년 후:   과거 고점이 창(window)에서 빠져나감
          → 새 52주 고점 5,700원
          → 5,450원이 "고점 -5% 이내" → 매도!
```

**주가가 오른 게 아니라 고점이 내려온 것.**
→ **매수가 대비 +N% 익절**로 변경 (절대 기준, 롤링창 무관)

### 5-2. 기저효과 (base effect)

```
삼성전자 2024 Q1: YoY +932%  ← 2023 Q1이 0.64조(사상 최악)였을 뿐
                                6.61조는 삼성 '평범한' 분기
                  5년평균 대비 -10.2% → 실제로는 "턴어라운드"
```

**증가율만 보면 "대호재"로 오판.** 5년 평균 대비를 함께 봐야 한다.

### 5-3. 실적은 후행, 주가는 선행

```
삼성전자 백테스트:
  실적 -55.2%(침체)일 때 매수 → +16.4%, +42.6%  ← 최고 수익!
  실적 +931.9%(대호재)일 때 매수 → -2.8%        ← 손실
```

**주가는 실적을 미리 반영한다.** 공시 시점엔 이미 늦음.
사이클 산업은 실적 바닥이 매수 기회 (저PER 함정과 같은 뿌리).

### 5-4. 떨어지는 칼날 (진양폴리)

```
2024-07: 6,070원 → 2026-07: 1,685원  (-72%)
52주 저점이 계속 갱신 → 매수 신호가 계속 발생 → 사면 또 떨어짐
52주 고점 대비 -163%까지 벌어짐 → 매도 신호 영원히 안 옴
```

**단순 VR: -61.5%.** 매수 필터(침체 제외)로 **아예 안 사게 됨.**

## 6. 버그 수정 (실전 테스트로 발견)

### 6-1. config 로드 순서 (치명적)

```python
_DEBT_RULES = _load_debt_rules()      # ← _REPO_ROOT 사용
_REPO_ROOT = Path(__file__)...        # ← 정의가 뒤에!
```

`NameError` → `except: pass` → **조용히 기본값 폴백 → config 통째로 무시.**
→ **`except: pass` 로 인한 조용한 실패가 가장 위험.** 전수 점검 필요.

### 6-2. YAML `none` 은 null 이 아니다

`debt: none` → 문자열 `'none'` / `debt: null` → 진짜 null

### 6-3. 현재가 조회 — CSV 캐시 의존

배당주 스캔이 갓 추가한 종목은 일봉 CSV가 없어 주가 None → 배당률 계산 불가.
→ `_price_of()`: `inquire_price`(실시간 API) 우선, CSV 폴백.

### 6-4. 조선 부채 규칙

선수금 = 부채 → 수주 많을수록 부채↑ → `debt: null` (판단 제외, 은행과 같은 논리).
검증: HD현대중공업 184%, 한화오션 205%, 삼성중공업 272% 모두 통과.

## 7. 백테스트 방법론 (재현용)

### 7-1. 룩어헤드 방지

**과거 시점 재무는 DART로만 가능** (KIS는 현재 시점만 준다).
공시 시점 = 분기 종료 + 45일 (Q1→5/15, Q2→8/15, Q3→11/15, Q4→익년 3/15)

```python
# dart_data: finstate_all(code, year, reprt_code, fs_div="CFS")
#   11013=1분기 11012=반기 11014=3분기 11011=사업보고서
#   "영업이익" 계정. 분기값은 단독(누적 아님). Q4 = 연간 - (Q1+Q2+Q3)
```

### 7-2. 배당 이력

`ksdinfo_dividend(f_dt, t_dt, sht_cd)` → 배당락일 + 주당배당금.
※ 금액 0인 건 미확정 (배당락일만 잡힌 상태) → 계산에서 제외.
보유 기간에 배당락일이 포함된 배당만 가산.
