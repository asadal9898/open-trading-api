## 1. 구현 완료 — 종목 평가 (재무 AND 차트)

### 원칙

**매수 = 재무 좋음 AND 차트 좋음.** 같은 차트를 스타일별로 정반대 해석.

| style | 재무 기준 | 차트 기준 | 성격 |
|-------|----------|----------|------|
| `value_range` (배당주) | 부채 + 영업이익 + **배당(필수)** | **52주 저점 근처** | 소외되어 싸질 때 산다 |
| `momentum` (공격적) | 부채 + 영업이익(**+10%↑**) | **정배열 (5>20>60)** | 추세를 따라간다 |
| `accumulate` (ETF) | **스킵** | 20일선 위 | 섹터 전망 + 차트 ※섹터전망 미구현 |
| `free_holdings` | 알림만 | 알림만 | 사람이 판단 |

### 파일

- `finance_data.py` — 재무 (부채·영업이익·배당·PER, `evaluate_financials`)
- `chart_eval.py` — 차트 (정배열 / 52주 저점, `evaluate_chart`)
- `stock_eval.py` — 결합 (`evaluate_stock` = 재무 AND 차트)
- `mytrading_config.yaml` — `style_rules`, `chart_rules`, `debt_industry_rules`, `op_profit_rules`, `dividend_filter`

## 2. ★★ style 분류가 백테스트로 검증됨

**같은 종목을 두 전략으로 각각 돌려 비교 (46종목, 2년):**

| 전략 | 매수 | 매도 | 평균 | **중앙값** |
|------|------|------|------|----------|
| **MOM** | 정배열 진입 | 정배열 이탈 | +1.8% | **-13.4%** |
| **VR** | 52주 저점 +5% | 52주 고점 -5% | +6.5% | **+5.5%** |

**배당주 = VR 압승:** 유아이엘 +93%p, SP삼화 +79%p, 케이씨피드 +78%p
**성장주 = MOM 압승:** 삼성전자 MOM +256.4% vs VR +6.4% (**-250%p**)

**→ 감으로 붙인 style 분류가 데이터로 검증됐다.**

### 재검토 필요

| 종목 | 현재 style | 문제 |
|------|-----------|------|
| **실리콘투** | momentum | VR이 52%p 우세, 정배열 비율 16% |
| SOL ETF 2종 | momentum | **`accumulate` 여야 함** (재무 평가받고 탈락 중) |

## 3. ★★★ value_range 최종 전략 (5년 검증)

### 3-1. 전략

```
[매수]   52주 저점 +5% 이내  AND  국면 ≠ 침체
[물타기] 평단 -30%  AND  국면 ≠ 침체  →  동일 금액 1회 추가 매수
[매도]   평단 대비 +15% 익절
[손절]   평단 -50% (최후의 안전장치)
```

### 3-2. 국면 판정 (2단계) — 기저효과 회피

**단순 YoY만 보면 속는다.** 5년 동일분기 평균을 함께 본다.

```
1단계: |YoY| < 25%  → "평범"
2단계: |YoY| >= 25% → 5년 동일분기 평균과 비교
```

| YoY | 5년평균 대비 | 국면 | 매수 |
|-----|------------|------|------|
| 증가 | +20% 이상 | 성장 | O |
| 증가 | +20% 미만 | 턴어라운드 | O |
| 감소 | 위 | 정점통과 | O |
| **감소** | **아래** | **침체** | **X ← 매수 금지** |

### 3-3. 5년 성과 (36종목, 134거래, 실제 배당 반영)

| 설정 | 평균 | 중앙값 | 승률 |
|------|------|--------|------|
| 손절 -15% | +6.2% | +4.4% | 81% ← **최악** |
| 손절 -20% | +8.7% | +8.1% | 83% |
| 손절 없음 | +9.1% | +13.6% | 83% |
| 손절 -30% | +10.3% | +10.1% | 81% |
| 손절 -25% | +10.5% | +8.6% | 89% |
| 손절 -40% | +10.9% | +12.8% | 83% |
| 손절 -50% | +11.8% | +13.6% | 86% |
| 물타기 -20% | +12.6% | +16.4% | 83% |
| 물타기 -30% | +12.8% | +15.3% | 83% |
| **물타기-30 + 손절-50 ★** | **+13.5%** | **+15.3%** | **83%** |

**기간별 (물타기 없이, 손절 -30%):**

| 기간 | 종목 | 거래 | 주가 | 배당 | 총수익 | 중앙값 | 승률 |
|------|------|------|------|------|--------|--------|------|
| 2년 | 34 | 60 | +6.3% | +6.4% | +12.7% | +16.7% | 74% |
| **5년** | 36 | 134 | +20.7% | +13.5% | **+34.2%** | +31.1% | **75%** |

**승률 74~75%가 기간에 무관하게 유지** → 전략이 견고하다는 신호.

## 4. ★★ 핵심 교훈

### 4-1. "뭘 살까" > "어떻게 팔까"

| 조정 | 2년 | 5년 | 결론 |
|------|-----|-----|------|
| **매수 필터 (침체 제외)** | +5.9% → **+10.9%** | (미검증) | ★ **유일하게 큰 효과** |
| 물타기 (-30%, 1회) | — | +10.3% → **+13.5%** | ○ 효과 있음 |
| 손절선 최적화 | +0.3%p | 느슨할수록 나음 | △ 미미 |
| 매도 전략 정교화 (4종) | 차이 없음 | — | X |
| 반등 확인 (E20) | +0.7%p | **-4.8%p** | **X 역효과** |
| 4단계 분할 매수 | -13.7%p | — | X 역효과 |
| 모아가기 v2/v3/v4 | -13.5%p | — | X 역효과 |

**"실적이 무너지는 종목만 안 사면 된다"가 거의 전부.**

### 4-2. 타이트한 손절은 해롭다

```
-15%: +6.2%  ← 최악
-50%: +11.8%
물타기: +13.5%  ← 최고
```

**배당주는 변동이 커서 -15~-20%가 자주 나오고, 그게 반등 직전인 경우가 많다.**
급하게 자르면 손해. **떨어질 때 더 사는 게 파는 것보다 낫다.**

### 4-3. 배당이 수익의 40~50%

```
2년: 주가 +6.3% + 배당 +6.4% = +12.7%
5년: 주가 +20.7% + 배당 +13.5% = +34.2%
```

**배당이 손실을 뒤집은 사례 (5년):**

| 종목 | 주가 | 배당 | 총 |
|------|------|------|-----|
| CR홀딩스 | **-30.0%** | **+74.5%** | **+44.5%** |
| 정상제이엘에스 | -21.8% | +28.8% | +7.1% |
| 모토닉 | -4.0% | +25.9% | +21.9% |

**오래 들고 있을수록 배당이 쌓여 주가 하락을 덮는다.**

### 4-4. 표본이 작으면 우연을 학습한다

**2년 손실 종목 8개로 필터를 만들려 했으나, 5년으로 늘리니 결과가 뒤집혔다:**

| 종목 | 2년 | 5년 |
|------|-----|-----|
| 현대공업 | -14.7% | **+74.5%** |
| KG스틸 | -14.6% | **+62.7%** |
| CR홀딩스 | -8.1% | **+44.5%** |
| 유아이엘 | **+33.9%** | -25.5% |
| 엠씨넥스 | **+20.2%** | -40.1% |
| 웹젠 | **+28.4%** | -24.9% |

**개별 종목의 성패는 기간에 따라 뒤집힌다.**
→ **"손실 종목을 걸러내는 필터"는 만들기 어렵다. 분산 투자가 답.**

**수익/손실 그룹 지표 비교에서도 유의미한 차이를 못 찾음:**
거래대금·자산·ROE·부채·배당률·배당추이 모두 변별력 없음.
(유일하게 "영업이익 장기추세"가 31.5%p 차이를 보였으나 예외가 많음)

## 5. 백테스트에서 발견한 함정

### 5-1. ★ 52주 고점 매도의 롤링 창 문제 (버그)

```
태경산업: 5,590 매수 → 5,450 매도 (-2.5%)  "고점매도"
```

**손실인데 "고점매도"?** 원인: **52주 고점이 내려왔다.**
과거 고점이 창(window)에서 빠져나가면서, 낮은 가격도 "고점 근처"가 된 것.

→ **매수가 대비 +15% 익절**로 변경 (절대 기준, 롤링창 무관)

### 5-2. 기저효과

```
삼성전자 2024 Q1: YoY +932%  ← 2023 Q1이 0.64조(사상 최악)였을 뿐
                  5년평균 대비 -10.2% → 실제로는 "턴어라운드"
```

### 5-3. 실적은 후행, 주가는 선행

```
실적 -55.2%(침체)일 때 매수 → +16.4%, +42.6%  ← 최고 수익!
실적 +931.9%(대호재)일 때 매수 → -2.8%       ← 손실
```

**사이클 산업은 실적 바닥이 매수 기회.**

### 5-4. 떨어지는 칼날 (진양폴리)

```
2024-07: 6,070원 → 2026-07: 1,685원  (-72%)
52주 저점이 계속 갱신 → 매수 신호 계속 발생
```

**단순 VR: -61.5%.** 매수 필터(침체 제외)로 **아예 안 사게 됨.**

## 6. 버그 수정

### 6-1. config 로드 순서 (치명적)

```python
_DEBT_RULES = _load_debt_rules()      # ← _REPO_ROOT 사용
_REPO_ROOT = Path(__file__)...        # ← 정의가 뒤에!
```

`NameError` → `except: pass` → **조용히 기본값 폴백 → config 통째로 무시.**
→ **`except: pass` 로 인한 조용한 실패가 가장 위험.** 전수 점검 필요.

### 6-2. YAML `none` 은 null 이 아니다

`debt: none` → 문자열 `'none'` / `debt: null` → 진짜 null

### 6-3. 현재가 조회 — CSV 캐시 의존

배당주 스캔이 갓 추가한 종목은 일봉 CSV가 없어 주가 None → 배당률 계산 불가.
→ `_price_of()`: `inquire_price`(실시간 API) 우선, CSV 폴백.

### 6-4. 조선 부채 규칙

선수금 = 부채 → 수주 많을수록 부채↑ → `debt: null` (판단 제외).

### 6-5. 배당주 스캔이 industry를 안 채움

`add_to_universe` 가 sector 만 넣고 industry 를 빠뜨림
→ 업종별 부채 규칙이 적용 안 됨. `dart_data.get_industry()` 추가.
기존 39종목의 industry 도 일괄 보충 (58/59 완료).

### 6-6. 부채 규칙에 "신탁"·"투자" 키워드 추가

한국자산신탁(투자기관)이 금융인데 일반 규칙(100%) 적용받고 있었음.

## 7. 백테스트 방법론 (재현용)

### 7-1. 룩어헤드 방지

**과거 시점 재무는 DART로만 가능** (KIS는 현재 시점만).
공시 시점 = 분기 종료 + 45일 (Q1→5/15, Q2→8/15, Q3→11/15, Q4→익년 3/15)

```python
# dart_data: finstate_all(code, year, reprt_code, fs_div="CFS")
#   11013=1분기 11012=반기 11014=3분기 11011=사업보고서
#   "영업이익" 계정. 분기값은 단독(누적 아님). Q4 = 연간 - (Q1+Q2+Q3)
```

### 7-2. 배당 이력

`ksdinfo_dividend(f_dt="20190101", t_dt=..., sht_cd=code)` → 배당락일 + 주당배당금.
※ 금액 0인 건 미확정 → 계산 제외. 보유 기간에 배당락일이 포함된 배당만 가산.

### 7-3. 데이터

- 일봉: `backtester/.lean-workspace/data/equity/krx/daily/{code}.csv`
- `daily_update.py --force` (휴장일엔 --force 필요)
- 거래일만 카운트 (같은 종가 반복 = 휴일 → 스킵)

### 7-4. 임시 스크립트 (정식 모듈로 옮길 것)
