### 1-2. 국면 판정 로직 통일 (구현 완료)

**문제**: 백테스트는 임시 스크립트의 `build_disclosed` / `phase_at` / `PUB` 상수로 국면을 판정했고,
실전 코드에는 국면 판정이 아예 없었음 → 로직이 두 벌로 갈라질 위험.

**해결: 로직 공유, 데이터 소스 분리**

`mytrading/dart_data.py`
- `_find_op_profit(df)` — 전체재무제표에서 영업이익 추출 (억원)
- `_disclosure_dates(code, year)` — DART `list(kind="A")` 로 실제 공시일(rcept_dt) 조회
- `get_quarterly_op(code, year)` — 분기별 영업이익 + 공시일 통합 반환
  - Q2 = 반기보고서 값(상반기 누적). 백테스트 재현 목적으로 `collect_op.py` 방식 유지
  - Q4 = FY - (Q1+Q2+Q3) 역산, 공시일은 FY(사업보고서) 공시일

`mytrading/finance_data.py`
- `_judge_phase_from_data(hist, rcepts, as_of)` — 순수 판정 로직 (실전·백테스트 공유)
- `_judge_phase(symbol, as_of=None)` — DART 수집 껍데기
- `is_buyable_phase(phase)` — 매수 가능 여부. 침체 및 None(판정불가) 배제
- `evaluate_operating_profit` — `phase`/`phase_yoy`/`phase_vs`/`phase_quarter`/`phase_note` 필드 추가.
  `passed`는 건드리지 않음 (종목 품질과 시점 국면의 관심사 분리)

**국면 5분류**

```
yoy = 당분기 / 전년동분기 - 1
vs  = 당분기 / 지난5년 동일분기 평균 - 1

|yoy| < 25%             → 평범
yoy >= 25%,  vs >= 20%  → 성장
yoy >= 25%,  vs <  20%  → 턴어라운드
yoy <= -25%, vs >  0    → 정점통과
yoy <= -25%, vs <= 0    → 침체        ★ 매수 배제
None (데이터 부족)       → 판정불가     ★ 매수 배제 (모르면 안 산다)
```

**검증**

- 공유 로직 vs 기존 백테스트 로직: 900건 중 893건(99.2%) 일치
- 불일치 7건은 전부 "전년 동기 없음" 케이스. 기존 로직이 직전 국면을 관성적으로
  유지하던 버그였고, 공유 로직이 정직하게 None을 반환하는 쪽이 옳음
- 통일 후 백테스트: 승률 83% → 86% (판정불가 매수를 배제해 오히려 개선)

### 1-3. 백테스트 현실성 검증 (전부 통과)

**룩어헤드 없음**
- 백테스트의 공시일 가정(Q1=5/15, Q2=8/15, Q3=11/15, FY=익년 3/15)이
  실제 DART 공시일과 ±1~4일 일치 (삼성전자·SK하이닉스 실측)
- `as_of`를 바꾸면 당분기·국면이 그 시점 기준으로 정확히 이동
  (삼성전자 2022~23 침체 → 2024 성장, 실제 반도체 사이클과 일치)

**체결 가정에 강건**
- "한국 주식은 종가가 시초가보다 낮다" 가설 → 데이터상 성립 안 함
  (67,079일 중 49.4%, 평균 종가/시가-1 = -0.028%)
- 체결 방식별 승률

  | 판단 / 체결 | 승률 |
  |---|---|
  | 당일종가 / 당일종가 | 86% |
  | **전일종가 / 다음날시가** | **89%** |
  | 전일종가 / 다음날종가 | 83% |
  | 당일종가 / 다음날시가 | 86% |

- 실전에서 쓸 방식(전일 종가로 판단 → 다음날 시가 매수)이 오히려 최고
- **실전 구현 지침**: 전일 종가 기준 판단 → 다음날 시가 체결

**손익비 건전 (착시 아님)**

102개 개별 트레이드 분해
- 승률 83% (85승 17패)
- 평균 승자 +21.2% (익절선 +15%보다 높음 — 갭상승 + 배당 때문)
- 평균 패자 -13.8%
- 손익비 1.54, 기댓값 +15.4% / 트레이드
- -50% 손절은 단 2건. 우려했던 비대칭(+15% / -50%) 피해 없음

**생존편향 미미**
- 시점별 유니버스(point-in-time) 백테스트 결과가 고정 유니버스와 완전 동일
- 이유: 배당률 필터가 이미 방어. 배당 시작 전에는 배당률 0이라 국고채 기준 미달로 매수 불가
- 남은 한계: 상장폐지 종목은 데이터 자체가 없어 복원 불가

### 1-5. 데이터 오염 발견 및 수정

**범위**

  → 현재 시점 배당률은 정상, 과거 구간만 오염

**영향 및 조치**
- 전체 성과: +16.9%/94% → +15.4%/92% (평균 -1.5%p)
- 개별 반전: CR홀딩스 +21.8% → -10.2%(승자가 패자로), 동국홀딩스 +50.1% → +29.0%

  → 배당률 50%는 데이터 오류, 실제 8.3%, 깨끗한 데이터로는 손실 종목

- 백테스트 시 `MAX_YIELD=15%` 초과 배당 레코드 제외로 대응

## 2. 2차 실전 이식 (2026-07-19) — 데이터 버그 수정 + 실전 코드화

### 2-1. 데이터 커버리지 버그 (CFS → OFS) — §1 수치가 편향됐던 원인

**증상**: 유니버스 76종목을 전수 판정하니 국면 "판정불가"가 7종목.
부채·영업이익·배당은 모두 통과인데 국면만 실패했음.

파보니 공시일(`rcept_dt`)은 정상 조회되는데 영업이익 금액만 `None`이었음.

```
DSR제강 2023  Q1~Q4: {'op': None, 'rcept': 2023-05-12 ...}   ← 보고서는 찾음
DSR제강 2025  Q1~Q4: {'op': 60.5, 'rcept': 2025-05-15 ...}   ← 2025부터만 정상
```

**원인**: `dart_data`와 구버전 `collect_op.py`가 `fs_div="CFS"`(연결재무제표)만 조회하고 있었음.
종속회사가 없는 소규모 기업은 연결재무제표를 작성하지 않고 개별(OFS)만 제출하므로 빈 결과가
돌아왔던 것.

실측 확인:

| 종목 | CFS(연결) | OFS(개별) |
|---|---|---|
| DSR제강 | 빈 결과 | 234.9억원 |
| 삼일기업공사 | 빈 결과 | 31.0억원 |
| 고려신용정보 | 130.7억원 | 117.1억원 |

**수정**: `get_quarterly_op` / `get_eps`에 CFS 우선 → 빈 결과면 OFS 폴백을 추가. 둘 다 있으면
CFS가 그룹 전체 실적이므로 우선.

**결과**: 판정불가 4종목이 모두 정상 판정으로 복구.

```
DSR제강        판정불가 → 평범     (YoY +8.6%)
삼일기업공사    판정불가 → 정점통과  (YoY -32.7%)
스튜디오삼익    판정불가 → 침체     (YoY -56.4%)  ← 실제로 나쁜 종목, 정당한 배제
감성코퍼레이션   판정불가 → 성장     (YoY +38.3%)
고려신용정보    평범 → 평범 (유지)               ← 대조군
```

**파급 — 백테스트 표본이 편향되어 있었다**: 이 버그 때문에 백테스트 종목 풀이 연결재무제표를
쓰는 기업(= 종속회사를 둔 비교적 큰 회사)으로 자동 선별되어 있었음. 36~41종목이었던 이유.
재수집 후 75종목으로 늘었고, 성과 수치가 전면 재평가됨(§2-3).

### 2-2. 데이터 재수집

세 데이터가 모두 필요하다. 수집 후 76종목 중 75종목이 백테스트 가능해졌다.

| 데이터 | 수집 경로 | 결과 |


`mytrading/collect_div.py` — 배당 이력의 원천은 DART가 아니라 `ksdinfo_dividend`(한국예탁결제원

⚠️ `ksdinfo_dividend`는 KIS 예제 폴더에 있어 직접 import가 안 됨. `import mytrading.finance_data`를

### 2-3. 성과 재평가 (75종목)

**종목 풀 확대의 영향**

| 연도 | 36종목 | 75종목 |
|---|---|---|
| 2021 | +8.1% | +10.6% |
| 2022 | +3.1% | **-17.6%** |
| 2023 | +17.6% | +8.7% |
| 2024 | -1.8% | -6.6% |
| 2025 | +14.0% | +23.8% |
| 2026 | +0.8% | +15.2% |
| **CAGR** | **+8.1%** | **+5.7%** |

2022년이 결정적으로 나빠졌다.

**2022년에 무슨 일이 있었나**

```
2022-01  보유  7종목  현금 33.6%   자산 1,105만
2022-02  보유 10종목  현금  5.9%   ← 한 달 만에 소진
2022-06  보유 11종목  현금  0.7%   ← 완전 고갈
2022-07  자산 961만 (급락)
2022-10  자산 922만 (최저)
```

하락장 초입에 자금을 다 써버렸다. 2월에 이미 만석, 6월엔 현금 0.7%. 그 뒤 시장이 더 빠졌지만
물타기도 저점매수도 할 수 없었다.

하락장에서는 여러 종목이 동시에 52주 저점+5%에 진입하므로 신호가 쏟아지고 자금이 순식간에
소진된다. 종목 풀이 클수록 심해지는 value 전략의 구조적 약점이다.

### 2-4. 현금 하한 (핵심 발견)

**스윕 결과**

| 현금 하한 | CAGR | 평균 보유 | 평균 현금 |
|---|---|---|---|
| 0% | +5.7% | 9.6종목 | 11.1% |
| **10%** | **+9.2%** | 9.3종목 | 15.6% |
| 20% | +8.4% | 7.8종목 | 25.5% |
| 30% | +6.5% | 6.4종목 | 34.6% |

**견고성 확인 — 2022년에만 맞춘 것이 아니다**

| 연도 | 하한 0% | 하한 10% | |
|---|---|---|---|
| 2021 | +10.6% | +10.7% | ≈ |
| 2022 | -17.6% | -8.4% | 개선 |
| 2023 | +8.7% | +12.0% | 개선 |
| 2024 | -6.6% | **+7.9%** | 마이너스 → 플러스 |
| 2025 | +23.8% | +27.6% | 개선 |
| 2026 | +15.2% | -0.9% | 악화 (부분 연도·미청산 평가손) |
| **누적** | **+31.8%** | **+54.9%** | |

6년 중 5년에서 개선되었다.

**왜 효과가 있나**: 현금 0%에서는 -30% 물타기 신호가 떠도 돈이 없어 실행하지 못했다.
백테스트가 검증한 물타기의 이득이 자금 부족으로 무력화되어 있었던 것.
현금을 남기면 하락장 초입에 전량 소진하지 않아 더 낮은 가격에 살 여력이 생기고, 물타기가
실제로 작동한다. 이것은 앞서(§1-6) 실패한 "타이밍 정교화"와 범주가 다르다.
매수 조건이 아니라 자금 관리를 바꾸는 것.

**⚠️ 정확한 값은 정할 수 없다**: 구현 방식을 바꾸자 같은 "10% 하한"이 +9.2%와 +6.2%로 3%p
차이가 났고, 자본금에 따라 10/15/20%의 순서가 뒤집혔다.

```
1,000만원:  10% +6.2%  <  15% +7.7%  <  20% +8.7%
2,000만원:  10% +8.7%  >  15% +6.9%  <  20% +8.0%   ← 비일관
```

견고하게 남는 결론은 "현금을 0까지 소진하지 말 것" 하나뿐이다. config의 `cash_floor: 15`는
10~20 범위에서 임의로 고른 값이며, 이 숫자를 근거로 다른 판단을 하면 안 된다.

### 2-5. 자산 규모 검증

2,000만원으로 돌려도 규칙이 그대로 작동한다.

| 자본금 | 평균 슬롯 | 평균 보유 | CAGR (최선값) |
|---|---|---|---|
| 1,000만원 | 9.0개 | 8.5종목 | +8.7% |
| 2,000만원 | 19.0개 | 16.6종목 | +8.7% |

슬롯 상한 20은 2,000만원 구간에서 실제로 걸리기 시작하며, CAGR이 동등하므로 상한 20을
유지해도 된다.

### 2-6. 실전 구현

**국면 게이트 (`stock_eval.py`)**: `style == "value_range"`일 때만 `is_buyable_phase()`를
`buy` 조건에 AND 결합. 침체·판정불가면 매수 보류. `passed`(종목 품질)는 건드리지 않음.

```
- 재무 O / 차트 O / 국면 평범  →  ★매수후보
- 재무 O / 차트 O / 국면 침체 ✗매수보류
```

**국면 판정 캐싱 (`finance_data.py`)**: `_judge_phase`는 종목당 DART를 30회 호출한다.
`(종목, 기준일)` 캐시를 추가했다.

```
1회차: 6.10초  →  2회차: 0.00초
```

**매도 규칙 (`order_pace.py`)**: 52주 고점 기준 매도를 제거했다. 내 매수가와 무관해 손실
구간에서도 매도 신호가 나서 백테스트와 어긋나기 때문. 대신 평단 기준
`position_action(pnl_percent, already_averaged)`를 신설했다.

```
+15% 이상   →  익절 (전량)
-50% 이하   →  손절 (전량)
-30% 이하   →  물타기 1회 (이미 물탔으면 보류)
그 외       →  보유
```

⚠️ 손절(-50%)이 물타기(-30%)보다 우선이다. 순서 주의.

**물타기 1회 제한 (`position_state.py`)**: 계좌 잔고에는 "이미 물탔는지" 정보가 없어 별도
상태 파일로 추적한다.

⚠️ D-2(moderate 자동매수, 모의)로 매수 성공 시 훅(`mark_bought`)은 실제로 연결됐지만, 그건
주기강제(A-3)용이고 **물타기 여부를 기록하는 훅(`mark_averaged_down`)은 여전히 호출부가
없다**(재확인: 정의·docstring뿐, 실제 호출 0곳). 계좌 수량 변화로 자동 감지하는 방식(최초
보유 시 `entry_qty` 기록 → 현재수량 > entry_qty면 물타기로 판단)으로 재설계가 필요하다는
결론은 그대로 유효하다(§4).

**매수 금액 산정 (`position_sizing.py`)**

```
예산      = 계좌 총평가금액 × allocations.yaml 카테고리 비중(%)
투자가능  = 예산 × (1 - cash_floor%)
슬롯수    = clamp(투자가능 ÷ min_unit, 1, max_slots)      내림
종목당    = 투자가능 ÷ 슬롯수
수량      = 종목당 ÷ 현재가                              1주 단위 내림
```

설정 (`mytrading_config.yaml` → `position_sizing`, 2026-08-14 코드로 재확인 — 아래 값 그대로 유효)

| 항목 | 값 | 비고 |
|---|---|---|
| `min_unit` | 1,000,000 | 슬롯당 최소 금액 |
| `max_slots` | 20 | 상한 도달 후엔 종목당 금액이 커진다 |
| `cash_floor` | 15 | **최적값 아님** — 10~20 범위 임의 선택 |
| `min_order_amount` | 300,000 | 미만이면 매수 건너뜀 |
| `allow_below_min_unit` | true | 투자가능액이 100만원 미만이어도 소액 매수 |

자산 규모별 산출 예시 (moderate 20% 기준)

| 총평가 | 예산 | 투자가능 | 슬롯 | 종목당 |
|---|---|---|---|---|
| 5,000만원 | 1,000만 | 850만 | 8 | 106만 |
| 1억원 | 2,000만 | 1,700만 | 17 | 100만 |

백테스트의 "1,000만원 × 10슬롯"은 실전에서 총평가 5,000만원 구간에 해당한다.

**배당 프리미엄**: `mytrading_config.yaml`의 배당 프리미엄을 코스피 0.5 → 0.0, 코스닥 1.0 → 0.0으로
조정했다(백테스트에서 국고채+0%p가 최적, §1-4). **2026-08-14 코드로 재확인 — `dividend_filter.kospi/kosdaq.premium` 둘 다 `0.0`으로 지금도 유지되고 있음.**

**매매 계획 연결 (`trade_plan.py`)**

```
미보유  →  52주 저점+buy_zone% AND 국면OK  →  금액·수량 산정  →  매수
보유    →  position_action(평단 대비 손익률)  →  익절/물타기/손절/보유
```

- 잔고 스냅샷은 실행당 1회만 조회 (모듈 전역 캐시)
- 국면 판정 실패 시 보수적으로 매수 보류 ("모르면 안 산다")
- 금액 산정 실패·미달 시 `action`을 `hold`로 되돌리고 사유를 기록

동작 확인

```
모토닉  hold
    52주 최저가 +4.3% (저점 근처, ≤5%) → 매수 보류: 주문금액 0원 < 최소 300,000원
```

자동 조절에 쓰려던 것.

**백테스트**: `research_backtest/dd_control_backtest.py` — 코스피(37년)·S&P500(21년)·나스닥100(36년),
임계 4종(-5/-10/-15/-20%), 거래비용 왕복 0.2%, 신호 다음날 반영.

**결과 — 코스피 기각**:
- 전체(1990~): buy&hold CAGR +5.4% → 규칙 적용 시 +1.6~2.7% (수익 절반~70% 상실)
- 2010년 이후: -15/-20% 임계는 MDD 방어 0 (급락 시 -15% 도달 시점이 이미 바닥 근처),
  -10%는 방어되지만 CAGR 40% 상실
- 어느 시대·임계든 교환비 나쁨. IMF 왜곡 아님 (기간 민감도 확인)
- 원인: 코스피 박스권(whipsaw) + 급락 시 V자 반등 (바닥에서 팔고 늦게 재진입)

**부수 관찰**: 나스닥100·S&P500은 -15~-20%에서 교환비 수용 가능
(나스닥 36년 거래 16회, MDD -83%→-33%, CAGR -3.7%p) — 미국 투자 시 참고.

**결론**: 한국 시장 리스크 관리는 이탈-재진입(타이밍)이 아니라 구조적 방어(현금하한 10~20%,
분산 슬롯, 종목별 손절/익절)가 답. 신용잔고 기각(§1-6)과 같은 메커니즘.

### 3-2. 실전 관찰: 2026-07-28~31 코스피 폭락·반등 (리스크 지표 검증)

7/27~7/30 코스피 -17% 폭락(6,756→5,594) → 7/31 +18% V자 반등(→6,595). 거래량 급증
(2.7억→4.6억). 이 실제 이벤트에서 리스크 지표들의 반응:

- **드로다운 컨트롤 기각 재확인**: -10% 이탈 규칙이었다면 7/28~29(저점 5,263) 바닥 근처에서
  현금화 → 7/31 +18% 반등 놓침. 백테스트 기각 판단이 실전에서 그대로 재현.
- **신용잔고 매매 무효 재확인**: 7/30→31 신용 -3.3조(32.2→28.9조, 반대매매 정점)이 오히려
  바닥. 하락 신호로 썼다면 정반대. 동행을 넘어 역행 가능.
- **RSI<25 희귀성 (신규)**: -17% 폭락에도 RSI 최저 31.2(7/30). 25 밑으로 안 감 → 이 바닥에서
  RSI 알림 신호 없음. RSI<25는 극단적·장기 하락만 잡는 희귀 신호로, 급격하지만 짧은 폭락은
  못 잡음. 단 임계 조정은 안 함(타이밍 정교화 함정, 승률 재검증 필요).

**결론**: 급락 시 타이밍 기반 방어(이탈·신용·RSI)는 모두 바닥을 놓치거나 역행. 구조적 방어
(현금하한·분산·손절)만 유효하다는 기존 결론 재확인.

### 3-3. 코어 배당주 수익성 검증 (2026-08-07) — 단순 보유 부적합

배당 지속성 검증(§1-2 수준1 방식)으로 뽑은 코어 26종목(5년 연속 배당+금리초과)을 2021 매수 후
2025말까지 단순 보유했을 때의 수익성. `research_backtest/core_dividend_backtest.py`.

결과 (5년, 배당 세전):
- 코어(배당포함): 총수익 +23.3%, CAGR +4.3%, MDD -34.2%
- 코어(가격만): -3.4% (주가는 5년간 제자리, 수익의 거의 전부가 배당)
- 코스피 B&H: +43.1%, CAGR +7.4%, MDD -34.8%
- 기존 value_range: CAGR +8.6%[^1]

★결론: 코어 배당주 단순 보유는 코스피에 크게 짐(+4.3% vs +7.4%). MDD 방어도 안 됨. 게다가
생존편향으로 유리한 조건(2025 시점 5년 통과 종목을 뒤돌아 선택)에서조차 진 것 — 실전은 더
낮음. 배당 지속성 ≠ 수익.

종목 양극화: 기아 +130%·한국컴퓨터 +117% vs 교촌 -41%·KG파이낸셜 -44%. 고배당이 오히려
"주가가 안 올라 배당률만 높은" 가치 함정일 수 있음.

교훈 재확인: "어떤 배당주인가"(종목 필터)보다 "언제 사고 파는가"(value_range 저점매수+익절)가
수익을 만든다. 코어 리스트는 매수 신호가 아니라 종목 후보 풀로만 활용.

[^1]: 이 수치는 이 검증(2026-08-07) 당시 참고용으로 쓴 기준값이며, §2-1의 데이터 편향으로
    이미 대체된 값이다(2026-08-14 기준 신뢰값 +5.7%~+9.2%, §0 참고). 최신값으로 바꿔도 결론은
    같다 — 코어 배당주 단순보유(+4.3%)는 대체 전(+8.6%) 대체 후(+5.7%~+9.2%) 어느 기준으로
    비교해도 value_range 전략보다 낮다(4.3% < 5.7% < 9.2%).
