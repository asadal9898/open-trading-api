# YOLO 차트 패턴 검출 — 시도와 기각

이미지 기반 AI 차트 패턴 검출(YOLOv8)을 매매 신호로 쓸 수 있는지 검증하고,
**기각한 기록.** 나중에 비슷한 "AI 차트 분석" 도구를 다시 검토할 때
"이미 해봤고 왜 접었는지"를 바로 참고하기 위한 것.

작성일: 2026-07-26
결론: **매매 신호로 쓸 수 없음.** 3겹의 독립 증거가 같은 답.

---

## 1. 무엇을 시도했나

Hugging Face의 차트 패턴 검출 모델(`foduucom/stockmarket-pattern-detection-yolov8`)로
캔들 차트에서 헤드앤숄더·쌍바닥(W_Bottom)·쌍봉(M_Head)·삼각수렴 등을 검출.

- 데이터: KIS 인프라(`data_manager.ensure_data`) + lean CSV → mplfinance 캔들 차트
- 검출: YOLOv8 추론 (6개 패턴 클래스)
- 스크립트: `chart_pattern_yolo.py`(단일 검출), `chart_pattern_backtest.py`(예측력 검증)

원본은 Gemini가 만든 yfinance 기반 코드였고, 데이터를 KIS로 바꾸고
버그(yfinance MultiIndex, 라벨 하드코딩, 무의미한 폴백, BASE_DIR)를 고쳤다.

---

## 2. 어떻게 검증했나 (룩어헤드 방지)

"모델이 패턴을 검출한 뒤, 실제로 그 방향으로 주가가 움직였나?"

과거 각 시점 T 마다:
1. **T 이전 120일 차트만으로** 이미지 생성 (미래 안 봄)
2. YOLO 추론 → 검출 패턴
3. T 이후 5·10·20일 실제 수익률 기록

집계: 패턴별 이후 수익률을 **기저(모든 시점 평균)와 비교**.
- 상승신호(W_Bottom, H&S bottom)는 기저대비 (+)여야 예측력 있음
- 하락신호(M_Head, H&S top)는 기저대비 (−)여야 예측력 있음

삼성전자 단독(294회 추론) + 3종목(삼성·현대중·현대차) 두 번 돌림.

## 3. 기각 근거 — 3겹의 독립 증거

### 3-1. 모델 스펙 자체가 부실

README에 제작자가 밝힌 값:
- **mAP@0.5 = 0.61** — 검출 정확도가 낮다(잘 만든 모델은 0.85~0.95).
- **"screen-captured trading data"로 학습** — HTS/트레이딩뷰 화면 캡처가
  학습 데이터. 우리가 생성한 mplfinance 차트와 근본적으로 다른 이미지다.

즉 검출을 맞히는 것 자체가 61% 수준이고, 우리 용도와 이미지 종류가 다르다.

### 3-2. 백테스트 — 예측력 없음

3종목(797시점) 기저대비 결과:

| 패턴 | 방향 | 5일 | 10일 | 20일 | 판정 |
|---|---|---|---|---|---|
| W_Bottom | ▲상승 | +0.08 | +0.14 | +0.17 | 거의 0 |
| H&S bottom | ▲상승 | -0.53 | -1.01 | -1.91 | **반대(마이너스)** |
| M_Head | ▼하락 | -0.23 | -0.43 | -0.66 | 방향 맞지만 미미 |
| H&S top | ▼하락 | +0.19 | +0.34 | +0.34 | **반대(플러스)** |
| Triangle | ―불명 | +2.62 | +8.13 | +6.74 | 표본 12개 — 우연 |

(단위 %p, 기저 대비)

- 상승/하락 신호의 기저대비가 **0 근처거나 방향이 반대**.
- 방향이 반대로 나온 패턴이 여럿(H&S bottom·H&S top) — 예측력이 있다면 불가능.
- 유일하게 튀는 Triangle은 **표본 12개**뿐 → 급등 구간에 우연히 몰린 것.
  ("표본이 작으면 우연을 학습한다" — value_range에서 얻은 교훈 그대로.)

### 3-3. 육안 — 검출이 근거 없음

삼성전자 검출 이미지에서:
- **정반대 패턴이 같은 자리에 겹침** — 5~6월 구간에 H&S top(하락)과
  W_Bottom(상승)이 포개져 검출. 둘 다 맞을 수 없다.
- **실제 패턴 모양과 무관** — W_Bottom 박스 안에 W자가 없고, H&S top도
  전형적 형태가 아니다. 그냥 적당한 구간에 박스를 친다.
- 신뢰도가 다 낮다(0.34~0.51).

## 4. 결론

**이미지 기반 AI 차트 패턴 검출은 이 프로젝트의 매매 신호로 쓸 수 없다.**

세 각도(모델 스펙·백테스트·육안)가 모두 같은 답이라 결론이 견고하다.
"AI가 패턴을 찾았다"는 그럴듯한 겉모습 뒤에 실제 예측력이 없었다.

이 검증 자체가 성과다 — 백테스트 없이 "AI 검출"을 믿고 매매에 넣었다면
노이즈에 돈을 걸었을 것이다. value_range·거시전망에 적용한 검증(룩어헤드
방지·기저 대비·표본 크기 경계)을 그대로 적용해 미리 걸러냈다.

### 다시 검토하게 된다면

- 스크린 캡처 스타일로 이미지를 맞춰도 mAP 0.61 모델이라 실익이 낮다.
- 검출을 잘해도 "패턴 → 수익"이 성립하는지는 별개 문제(백테스트가 이미 기각).
- 새 모델을 시험하려면 `chart_pattern_backtest.py`의 룩어헤드-안전 프레임을
  재활용할 것. 기저 대비로 예측력을 먼저 확인하고, 표본이 충분한지 볼 것.
