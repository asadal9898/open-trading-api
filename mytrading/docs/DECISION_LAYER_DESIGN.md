# 종합 판단 구조 설계 (데이터 계층 → 종목/시장 판단)

> 작성: 2026-07 / 상태: **설계 메모** (구현 전, 큰 그림)
> 핵심: 재무만이 아니라 거시(금리·환율·유가·지수) + 리포트 + 시장 강세까지
> 모두 종합해서 종목·시장을 예측·판단한다. 지금 데이터 계층은 다 준비됨.
> **빠진 것은 "데이터 → 판단"으로 엮는 로직.**

---

## 1. 큰 그림 — 4개 계층

```
                    ┌─────────────────────────────┐
                    │   [4] 매매 실행 (준비됨)      │
                    │  trade_plan → allocation     │
                    │  → compute_slice → submit    │
                    └──────────────▲──────────────┘
                                   │  "이 종목 살까/팔까/얼마나"
                    ┌──────────────┴──────────────┐
                    │   ★ 종합 판단 (빠진 연결)     │  ← 이 문서의 주제
                    │  미시 + 거시 + 리포트 결합     │
                    └──▲────────────▲────────────▲─┘
                       │            │            │
        ┌──────────────┴──┐ ┌───────┴──────┐ ┌───┴──────────────┐
        │ [1] 종목 미시    │ │ [2] 시장 거시 │ │ [3] 리포트 해석   │
        │  재무·차트·배당   │ │  지수·금리·   │ │  KCIF INSIGHT     │
        │                  │ │  환율·유가    │ │  (금융·실물)      │
        └──────────────────┘ └──────────────┘ └───────────────────┘
             (준비됨)            (준비됨)           (준비됨, 오늘 완성)
```

**핵심**: [1][2][3] 데이터는 다 있다. [4] 실행도 있다.
**비어있는 건 가운데 ★ — 데이터를 종합해 "판단"으로 만드는 층.**

## 2. 계층별 준비된 재료 (실제 함수)

### [1] 종목 미시
| 종류 | 함수 | 제공 |
|------|------|------|
| 재무 | `finance_data.get_financial_summary(symbol, industry)` | 부채·ROE·영업이익·매출증가율·debt_note |
| 재무 | `finance_unified.get_financials_safe(code)` | KIS 우선 + DART 폴백 |
| 재무 | `dart_data.get_financials/full(code, year)` | DART 원천 재무 |
| 차트 | `data_manager.get_trend(symbol)` | 5/20/60일선·기울기 |
| 차트 | `backtest_weekly_support.trend_score(weekly, idx)` | 주봉 추세 점수(신고가·신저가·이평) |
| 배당 | `finance_data.get_dividend_yield(symbol, price)` | 시가배당률 |
| 신호 | `order_pace.value_range_signal(symbol)` | 52주 저점/고점 매수·매도 신호 |

### [2] 시장 거시
| 종류 | 함수 | 제공 |
|------|------|------|
| 국면 | `common.get_regime(market)` | bull/bear/sideways/toppish ※사람이 config에 설정 |
| 국면 | `common.regime_for_symbol(symbol)` | 종목별 적용 국면(국내/해외) |
| 데이터 | `index_data.ensure_all_indices()` | 지수6·환율4·금리4·원자재3 (17개 CSV) |

### [3] 리포트 해석 (KCIF INSIGHT)
| 파서 | 제공 |
|------|------|
| `parse_key_indicators` | 국제·국내 금융시장 지표 시계열 (주식·채권·외환·상품·KOSPI·원화·국고채) |
| `parse_real_economy` | 국제·한국 실물경제 (성장률·물가·PMI·수출·경상수지) |
| `parse_ib_us_rates` | IB 미국 정책금리 전망 |
| `parse_world_economic_forecast` | 세계 경제성장률 전망 |

### [4] 매매 실행
| 함수 | 역할 |
|------|------|
| `trade_plan.build_plan(category)` | 매매 계획 지휘소 (style별 신호 분기) |
| `allocation_plan.build_plan(...)` | 목표 비중 대비 차액 |
| `order_pace.compute_slice(style, regime, direction)` | 국면×스타일 비중 |
| `order_pace.is_trade_day(cadence)` | 오늘 거래일인가 |
| `portfolio.tradable_symbols()` | confirm=Approval 종목만 |

## 3. 빠진 연결고리 (구현 대상)

### 3-1. 거시 데이터 → 국면 판단 (반자동)
**현재**: 국면(regime)은 사람이 config에 수동으로 적음. 거시 데이터(지수·금리·환율·유가)와 KCIF 지표는 "참고만".
**목표**: 거시 데이터·KCIF 지표를 종합해 **"국면 판단 보조 신호"** 를 제시.
- 예: S&P500 추세↓ + 금리 급등 + 유가 급등 + KCIF 실물 둔화 → "약세 신호, bear 검토 권고"
- ⚠️ **자동 전환은 안 함** — 사람이 최종 판단(차영석 원칙: 큰 판단은 사람). 시스템은 근거 제시까지.
- 산출물: "국면 판단 대시보드" (텔레그램 or 리포트) — 각 지표 상태 + 종합 코멘트.

### 3-2. 종목 미시 결합 (재무 + 차트) — FUNDAMENTAL 5번
**현재**: 재무 점수·차트 점수 각각 존재, 결합 없음.
**목표**: 하나의 종목 신호로 결합.
- 척도 정규화: 부채%·ROE%·증가율% + 추세점수 → 공통 스케일(예: 0~100 or -2~+2).
- 결합 규칙: 가중합? 필터(재무 미달이면 차트 무시)? — **투자 철학 반영, 신중히**.
- 결합에 거시([2]) 곱하기: bull이면 차트 가중↑, toppish면 재무 안정성 가중↑ 등.

### 3-3. 종합 판단 → 매매 계획 연결
**현재**: trade_plan은 style·regime·slice로 매매. 재무·리포트는 안 봄.
**목표**: 종합 판단 결과를 trade_plan 입력으로.
- 예: 재무 나쁨 → Approval이어도 매수 보류 or slice 축소.
- 예: 거시 약세 신호 → 신규 매수 자제.

## 4. 종합 판단 흐름 (구상)

```
[매주/매일 판단 사이클]

1. 거시 갱신: index_data (지수·금리·환율·유가) + KCIF 파서 (최신 호)
        │
        ▼
2. 시장 국면 보조신호 산출 (3-1)
   - 지수 추세, 금리 방향, 환율, 유가, KCIF 실물·금융 지표 종합
   - → "현재 시장: 강세/중립/약세 신호 + 근거"  ※사람이 보고 regime 확정
        │
        ▼
3. 종목별 신호 산출 (3-2)
   - tradable_symbols(Approval) 각각:
     · 재무 (get_financial_summary) — 업종별 부채 해석
     · 차트 (get_trend / trend_score)
     · 배당·저점 (value_range_signal)
     · → 결합 점수 + 국면 가중
        │
        ▼
4. 매매 계획 (3-3 → 기존 trade_plan)
   - 종합 판단이 양호 + 국면 우호 → 매수 계획
   - 재무 악화 or 거시 약세 → 보류/축소
        │
        ▼
5. 사람 확인 → 실행 (모의 → 실전)
```

## 5. 원칙 (차영석)

- **큰 판단(국면)은 사람.** 시스템은 데이터 종합·근거 제시까지. 자동 전환 안 함.
- **재무가 차트를 받쳐야.** 차트만으론 위험(수급 급변 잦은 한국장).
- **거시가 미시를 지배.** 종목 좋아도 시장 약세·금리급등이면 신중.
- **검증된 것만 자동화.** 결합 규칙은 백테스트(FUNDAMENTAL 6번) 통과 후 반영.
- **모의 우선.** 실주문 자동화는 충분한 모의 검증 후.

---

## 6. 구현 우선순위 (제안)

1. **국면 보조신호 대시보드** (3-1) — 거시+KCIF 지표를 모아 시장 상태 보여주기.
   자동 매매 아니라 "사람 판단 돕기"라 리스크 낮고 바로 유용.
2. **종목 미시 결합** (3-2, FUNDAMENTAL 5) — 재무+차트 결합 점수.
3. **백테스트 검증** (FUNDAMENTAL 6) — 결합 규칙이 실제 수익인지. ★가장 어려움.
   - 난점: 과거 시점 재무 데이터 확보, 룩어헤드·생존편향 회피.
4. **종합 판단 → trade_plan 연결** (3-3) — 검증 후.

→ 1번(대시보드)부터. 데이터는 다 있으니 "모아서 보여주기"가 첫 걸음.
   2·3은 결합 규칙+검증이라 무겁고 신중. 4는 맨 마지막(실매매 영향).
