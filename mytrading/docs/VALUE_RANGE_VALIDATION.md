## 2. 국면 판정 로직 통일 (구현 완료)

### 문제

백테스트는 임시 스크립트의 `build_disclosed` / `phase_at` / `PUB` 상수로 국면을 판정했고,
실전 코드에는 국면 판정이 아예 없었음 → 로직이 두 벌로 갈라질 위험.

### 해결: 로직 공유, 데이터 소스 분리

**`mytrading/dart_data.py`**

- `_find_op_profit(df)` — 전체재무제표에서 영업이익 추출 (억원)
- `_disclosure_dates(code, year)` — DART `list(kind="A")` 로 실제 공시일(rcept_dt) 조회
- `get_quarterly_op(code, year)` — 분기별 영업이익 + 공시일 통합 반환
  - Q2 = 반기보고서 값(상반기 누적). 백테스트 재현 목적으로 `collect_op.py` 방식 유지
  - Q4 = FY - (Q1+Q2+Q3) 역산
  - Q4 공시일 = FY(사업보고서) 공시일

**`mytrading/finance_data.py`**

- `_judge_phase_from_data(hist, rcepts, as_of)` — **순수 판정 로직** (실전·백테스트 공유)
- `_judge_phase(symbol, as_of=None)` — DART 수집 껍데기
- `is_buyable_phase(phase)` — 매수 가능 여부. 침체 **및 None(판정불가)** 배제
- `evaluate_operating_profit` — `phase` / `phase_yoy` / `phase_vs` / `phase_quarter` / `phase_note`
  필드 추가. **`passed` 는 건드리지 않음** (종목 품질과 시점 국면의 관심사 분리)

### 국면 5분류

```
yoy = 당분기 / 전년동분기 - 1
vs  = 당분기 / 지난5년 동일분기 평균 - 1

|yoy| < 25%             → 평범
yoy >= 25%,  vs >= 20%  → 성장
yoy >= 25%,  vs <  20%  → 턴어라운드
yoy <= -25%, vs >  0    → 정점통과
yoy <= -25%, vs <= 0    → 침체        ★ 매수 배제
None (데이터 부족)       → 판정불가     ★ 매수 배제 (모르면 안 산다)
```

### 검증

- 공유 로직 vs 기존 백테스트 로직: 900건 중 893건(99.2%) 일치
- 불일치 7건은 전부 "전년 동기 없음" 케이스. 기존 로직이 직전 국면을 관성적으로
  유지하던 버그였고, 공유 로직이 정직하게 None 을 반환하는 쪽이 옳음
- 통일 후 백테스트: 승률 83% → 86% (판정불가 매수를 배제해 오히려 개선)

## 3. 백테스트 현실성 검증 (전부 통과)

### 룩어헤드 없음

- 백테스트의 공시일 가정(Q1=5/15, Q2=8/15, Q3=11/15, FY=익년 3/15)이
  실제 DART 공시일과 **±1~4일 일치** (삼성전자·SK하이닉스 실측)
- `as_of` 를 바꾸면 당분기·국면이 그 시점 기준으로 정확히 이동
  (삼성전자 2022~23 침체 → 2024 성장, 실제 반도체 사이클과 일치)

### 체결 가정에 강건

- "한국 주식은 종가가 시초가보다 낮다" 가설 → **데이터상 성립 안 함**
  (67,079일 중 49.4%, 평균 종가/시가-1 = -0.028%)
- 체결 방식별 승률

  | 판단 / 체결 | 승률 |
  |---|---|
  | 당일종가 / 당일종가 | 86% |
  | **전일종가 / 다음날시가** | **89%** |
  | 전일종가 / 다음날종가 | 83% |
  | 당일종가 / 다음날시가 | 86% |

- 실전에서 쓸 방식(전일 종가로 판단 → 다음날 시가 매수)이 오히려 최고
- **실전 구현 지침**: 전일 종가 기준 판단 → 다음날 시가 체결

### 손익비 건전 (착시 아님)

102개 개별 트레이드 분해

- 승률 83% (85승 17패)
- 평균 승자 **+21.2%** (익절선 +15%보다 높음 — 갭상승 + 배당 때문)
- 평균 패자 **-13.8%**
- 손익비 **1.54**, 기댓값 **+15.4% / 트레이드**
- -50% 손절은 단 2건. 우려했던 비대칭(+15% / -50%) 피해 없음

### 생존편향 미미

- 시점별 유니버스(point-in-time) 백테스트 결과가 고정 유니버스와 **완전 동일**
- 이유: 배당률 필터가 이미 방어. 배당 시작 전에는 배당률 0이라 국고채 기준 미달로 매수 불가
- 남은 한계: 상장폐지 종목은 데이터 자체가 없어 복원 불가

### 프리미엄 스윕 결과 (오염 제거 후)

| 기준 | 종목 | 매수 | 평균 | 승률 |
|---|---|---|---|---|
| 필터만 (배당 무시) | 36 | 121 | +13.7% | 86% |
| 국고채 -0.5%p | 36 | 92 | +13.5% | 86% |
| **국고채 +0.0%p** | 36 | 86 | **+15.4%** | **92%** |
| 국고채 +0.5%p (현재 실전) | 36 | 77 | +14.6% | 92% |
| 국고채 +1.0%p | 34 | 70 | +13.3% | 91% |

- **국고채+0%p 가 최적** (0%p 정점 후 하락하는 곡선)

- 현재 실전(+0.5%p) 대비 **+0.8%p 개선 여지**
- **배당 필터 자체의 가치 입증**: 필터만 +13.7%/86% → +0%p +15.4%/92%
- 주의: 2021~26 평균 국고채는 **2.83%** (현재 3.85%보다 낮음).
  현재 금리로 과거를 고정 근사하면 기준이 과하게 엄격해 보이는 착시 발생

## 5. 데이터 오염 발견 및 수정

### 문제

일봉 CSV는 **수정주가**(액면분할·지주사 전환 소급 반영)인데,
`div_history_5y.json` 의 배당금은 **당시 원본값**이라 조정 안 됨
→ 기업 이벤트를 겪은 종목의 **과거** 배당률만 부풀려짐

예시

- CR홀딩스 2022년: 배당 4,500원 / CSV주가 8,253원 = **54.5%** (불가능)
- CR홀딩스 현재: 배당 410원 / 주가 4,880원 = 8.4% (정확)
- 배당금이 11배 줄어든 것이 분할의 흔적

### 범위

- 2021년 이후 배당 이벤트 235건 중 오염 **5건(2.1%), 2종목**
  (동국홀딩스 3건, CR홀딩스 2건)
- `universe.yaml` AI 기록값과 대조: 15종목 중 13종목 1.0x 일치
  → **현재 시점 배당률은 정상**, 과거 구간만 오염

### 영향 및 조치

- 전체 성과: +16.9%/94% → **+15.4%/92%** (평균 -1.5%p)
- 개별 반전: CR홀딩스 +21.8% → **-10.2%** (승자가 패자로), 동국홀딩스 +50.1% → +29.0%
- **폐기된 해석**: "CR홀딩스는 침체+적자여도 배당률 50%라 승자였다"
  → 배당률 50%는 데이터 오류, 실제 8.3%, 깨끗한 데이터로는 손실 종목
- 배당 필터의 가치는 235건 전체 패턴에서 나온 것이라 5건 오염과 무관하게 유효
- 백테스트 시 `MAX_YIELD=15%` 초과 배당 레코드 제외로 대응

- **배당락 전 20일**: 중앙값 -0.18%, 상승 47% → 수급 유입 근거 없음
  (순환논리 제거 후 고배당이 오히려 덜 오름: +1.27% vs 저배당 +3.62%)
- **배당락 후 10일**: 중앙값 -0.40%, 상승 46% → "과대낙폭 매수" 근거 없음

### 물타기는 유지해야 함

- 제거 시 평균 +14.8% → +12.5% (역효과)
- 손실 트레이드 5건 중 4건이 물타기 후 추가 하락했지만,
  성공 물타기(15건 평균 +4.8%)의 이익이 실패 손실보다 큼
- 단일 물타기(-30% 1회)는 유효. 다단계 분할은 실패

### 핵심 교훈

**"뭘 살까"(재무·국면·저평가·배당)는 먹히고, "언제 살까"(타이밍 정교화)는 전부 실패.**

value 전략의 본질상, 매수 시점에 좋아 보이는 종목(성장·고YoY)이 오히려 손실로 이어짐.
반대로 나빠 보이는 시점(침체·적자)에 산 것이 승자가 되는 역발상 구조.

## 드로다운 컨트롤 검증 (2026-08-06) — 기각

**아이디어**: 코스피 고점 대비 -X% 빠지면 이탈(현금), -Y%까지 회복하면 재진입.
free 한도 자동 조절에 쓰려던 것.

**백테스트**: dd_control_backtest.py — 코스피(37년)·S&P500(21년)·나스닥100(36년),
임계 4종(-5/-10/-15/-20%), 거래비용 왕복 0.2%, 신호 다음날 반영.

**결과 — 코스피 기각**:
- 전체(1990~): buy&hold CAGR +5.4% → 규칙 적용 시 +1.6~2.7% (수익 절반~70% 상실)
- 2010년 이후: -15/-20% 임계는 MDD 방어 0 (급락 시 -15% 도달 시점이 이미 바닥 근처),
  -10%는 방어되지만 CAGR 40% 상실
- 어느 시대·임계든 교환비 나쁨. IMF 왜곡 아님 (기간 민감도 확인)
- 원인: 코스피 박스권(whipsaw) + 급락 시 V자 반등 (바닥에서 팔고 늦게 재진입)

**부수 관찰**: 나스닥100·S&P500은 -15~-20%에서 교환비 수용 가능
(나스닥 36년 거래 16회, MDD -83%→-33%, CAGR -3.7%p) — 미국 투자 시 참고.

**결론**: 한국 시장 리스크 관리는 이탈-재진입(타이밍)이 아니라 구조적 방어
